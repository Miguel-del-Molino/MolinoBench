

# Translation Models: Baseline and Fine-Tuning

This directory contains scripts to run **baseline** and **fine-tuned** models for **mBART-50** and **NLLB-200**. You can use these scripts to generate translations and evaluate them against ground-truth sentences.

---

## **Required Files**

To perform evaluation, you need:

- `test.lt` – source sentences in Latin
- `test.es` – ground-truth target sentences in Spanish

These files are used to compare the sentences generated by the models against the reference translations.

---

## **Scripts Overview**

| Script | Description |
|--------|-------------|
| `run_baseline_model_mBart50.py` | Run mBART baseline model without fine-tuning |
| `run_finetune_mbart50.py` | Fine-tune mBART model on your dataset |
| `run_baseline_model_NLLB.py` | Run NLLB-200 baseline model without fine-tuning |
| `run_finetune_NLLB.py` | Fine-tune NLLB-200 model on your dataset |

---

## **Usage**

### 1. Run mBART Baseline (no fine-tuning)
```bash
python run_baseline_model_mBart50.py

```


### 2. Run NLLB Baseline (no fine-tuning)
```bash
python run_baseline_model_NLLB.py

```



### 3. Run the fine-tuning of mBart:
```bash
python run_finetune_mbart50.py

```


### 4. Run the fine-tuning of NLLB:
```bash
python run_finetune_NLLB.py

```
